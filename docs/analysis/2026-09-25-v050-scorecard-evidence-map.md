# v0.5.0 점수판 ↔ 증거 대응표 (9/25)

재범 결정(9/25 00:3x): v0.5.0 은 점수판(110점) 기준으로 가장 안전하게 전부 증명되는 버전이다.
이 표는 **증거 대응표**다. 처음(9/25 00:3x)에는 제안이었다. 판정(#696 댓글, 9/25 00:17)을 반영했다. 동결 뒤 "증거 대응표 최종" 으로 유지한다. protocol 은 이 문서가 고치지 않는다(protocol 작성 · validate 는 별도, 동결은 재범 승인).

**범위**: 처음 재범 결정은 105점(발표 · 시연 5점 제외)이었다. 105 계획 카드(9/25)에서 110점 전부로 넓혔다. 3.6 행도 채운다.

**판정 뒤 attempt 15개**: A 1·2·3 bed_a1 · A 4·5 station_b · B 6 10건 · C 7·8 Play/Stop · D 9·10 N=2 · B′ 11 beds-all · **E 12 다중 PC 1건 · E 13 다중 PC 10건 · 14 seed 11 · 15 seed 23**(A 형식). timeout 7200 s 그대로. 회피 더미 · 보행자는 구성 기본 ON 이다. 15개 모두에 들어간다.

- 기준: main `e9fa2e8`. protocol 은 [hospital-full-acceptance-v1](../../experiments/protocols/hospital-full-acceptance-v1.json)(#682, status `proposed`)이다.
- protocol 의 attempt 번호(repetition_index, seed 7 한 블록): **A** 1·2·3 = `ord-0001` → bed_a1, 4·5 = station_b 1인 · **B** 6 = 10건 · **C** 7·8 = Play/Stop · **D** 9·10 = N=2 · **B′** 11 = beds-all.
- protocol purpose 0: **동결 전에 돈 회차는 이 protocol 의 evidence 로 등록하지 않는다.** 아래 "이미 있는 회차" 는 회고 관측이다. 동결 뒤 같은 attempt 를 다시 돌려야 증거가 된다.
- 점수판 항목은 [평가 문서](../reference/tutor/final-presentation-evaluation.md) 3절 전사 그대로다. 회차 ID 는 #240 댓글이다.
