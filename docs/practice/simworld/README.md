# 심월드 실습 기록

[전체 실습 안내와 공통 기록 규칙](../README.md)

병원 USD 기반 실습을 관리한다. 정지 합성과 수납 애니메이션은 실제 팔·레일 동작 검증이 아니다. 빈월드와의 좌표 대조는 이 환경의 통합 준비로 기록한다.

[실습37](practice-37.md)에서 #490의 이전 후보 `c27d0d0`로 원통 3회 이송·홈 복귀를 관측했다. 속도 초과·모듈 간섭·내부 흡입 미구현이 남아 전체 합격이 아니며, #490 최신 코드의 L3 검증으로 보지 않는다.

## 기존 기록

## 새 일지 작성

새 심월드 일지는 이 디렉토리에 `practice-NN.md`로 만든다. 번호는 전체 실습 색인에서 중복되지 않게 정하고 이 표에 링크를 추가한다.
실행 SHA, 장면/로컬 설정 해시, 실제 실행 여부, 사람이 본 것과 로그 관측, 실패/미실행 항목, 후속 PR, 외부 로그·캡처 위치를 적는다. 현장 좌표·자산 절대 경로를 공용 실행 설정으로 올리지 않는다.

실습38을 이어받을 때는 [위치·배치 입력과 재개 절차](../../runbooks/practice38-handoff.md)를 확인한다.
