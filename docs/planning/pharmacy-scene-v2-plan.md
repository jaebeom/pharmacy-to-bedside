# 조제실 장면 변경 계획 (9/18 재범 결정)

- 상태: **진행 중(9/18 밤 기준).** 1-4단계를 9/18 에 했다(장면 #170, 팔 v2 #177, 실습6·7·8). 6단계(세준 USD 이식)가 남았다. 아래 본문은 재범이 2026-09-18 에 정한 장면 변경과 그 작업 순서다. 전달받은 내용 그대로 적었고, 해석을 더하지 않았다.
- 대상: 빈 월드 조제실 스테이지(`sim/standalone/pharmacy_stage.py`)와 M0609 팔 노드. 그 다음 세준의 실제 병원 USD 로 옮긴다.
- 관련: [시나리오](scenario.md)(M0609 는 2축 레일 위, #101), [실습 기록](../practice/README.md)(실습1-5 에서 드러난 문제).

## 재범이 정한 변경 다섯 가지

| 번호 | 변경 | 비고 |

| 5 | 5분 동안 투입을 연속으로 한다. 선반의 약통은 랜덤으로 집는다 | |

그 다음 세준의 실제 USD 에 같은 구성을 적용한다.

## 원칙

- 기존 preset 과 팔 기본값은 그대로 둔다. 9/21 시연의 대비책이다.
- 새 장면은 새 preset·새 파라미터로만 켠다.
- 치수는 매개변수로 두고 지금은 임시값을 쓴다. 세준 USD 의 값으로 바꾼다.
- 계약 v1 과 `Refill` 인터페이스는 바꾸지 않는다.
